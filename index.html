PadShifter

A dual-mode productivity application that combines a visual canvas and a text editor into a single, unified workspace — organized around application-specific notes.

v1.0.3 — User Guide & Keyboard Shortcuts Reference

About PadShifter

PadShifter is designed for Windows and gives you a persistent, personalized workspace for every application you use. It monitors which application is in the foreground and instantly presents the notes, canvases, and editor tabs you created for that specific app.

Whether you're organizing reference images for a design project, or keeping track of research links in your browser — PadShifter keeps everything neatly separated and always at hand.

The Core Idea

PadShifter monitors the foreground application and presents a personalized workspace for each one. Within every application's workspace you can create multiple tabs, and each tab can be either:

  • 📓 A Canvas — a freeform visual surface for arranging images, placing text blocks, and drawing freehand annotations.
  • 📝 A Text Editor — with built-in highlighting for Markdown, links, code spans, dates, e-mails, file paths and numbers with units, search/replace, auto-bracket closing, bracket highlighting, and RTL/LTR text auto-detection (including Arabic and Hebrew).

This means you can have one set of notes for your IDE, another for your browser, another for your design tool, and so on — each with its own collection of canvas and text tabs, all persisted automatically.

How It Works

  1. Launch PadShifter. The window appears (optionally in the system tray if configured to start hidden).
  2. Switch to your target application. PadShifter detects the foreground app and loads its associated workspace.
  3. Create tabs. Add text editor tabs for notes, snippets or longer text, and canvas tabs for visual organization.
  4. Work freely. Add images, draw, write text, and arrange everything. Changes are auto-saved.
  5. Switch apps. When you move to another application, PadShifter seamlessly loads that app's workspace.
  6. Return anytime. All state is preserved — zoom levels, scroll positions, open tabs, canvas layouts, everything.

Canvas Mode Canvas

The Canvas is an infinite workspace where you can:

  • Import and arrange images — drag and drop or paste images from the clipboard. Images can be resized, rotated, cropped, and adjusted for opacity; right-click → Transform gives Flip Horizontal, Flip Vertical and Reset Transform (Ctrl + Shift + 1).
  • Add text blocks — place formatted text anywhere on the canvas with control over font, size, color, bold, italic, underline, strikethrough, line spacing and alignment (the L/C/R button in the text toolbar opens a Left / Center / Right menu, and the ×-value button opens a 0.5×-to-2.0× menu for multi-line blocks — 1.0× is the font's natural spacing and values below it tighten fonts whose default spacing is loose; both buttons show the current choice). While typing, Shift+Enter adds a new line; Enter or clicking away finishes the text.
  • Freehand draw — use the pen tool to sketch annotations, highlights, and freehand strokes with configurable color, thickness, and smoothing levels.
  • Eyedropper — press the “Pick Color from Canvas” toolbar button, then click any pixel: that color becomes your current stroke and text color, and it is also copied to the clipboard as a hex code (for example #4A90D9) ready to paste anywhere. Any selected text or strokes take the color too — one undo reverses the pick (a locked group is left untouched). Press Escape to cancel before clicking.
  • Group and lock items — group related elements together and lock them to prevent accidental changes.
  • Organize with layout tools — right-click → Arrange lays everything out as a uniform grid, a square, an equal-height row, a proportional row, an equal-width column, a proportional column. Align and distribute selected items precisely.
  • Adjust z-order — move items forward, backward, to front, or to back.
  • Use smart guides and grid — snap-to-grid and alignment guides help you place items precisely.
  • Zoom and pan — navigate large canvases with smooth zooming and panning, and right-click → View → Fit All Images to frame the whole board at once.
  • Undo/redo — full history management with a configurable undo depth (up to 1000 steps).
  • Clear the board — right-click → Clear Canvas removes every image and text block after a confirmation prompt except for the locked group, while Clear All Strokes erases your drawings and leaves everything else alone.
  • Export the viewport — export the current canvas view as a PNG file at 1×, 2× or 4× (right-click → Export → Export Canvas as PNG): 1× is the size you see, while 2×/4× re-render text and lines razor-sharp and pull photos up to their source detail. Ctrl+E exports at your last-picked scale.
  • Export selected images — select images and right-click → Export → Export Images… to copy their original files into a folder you pick: files are never overwritten — a name that already exists there (or repeats within the batch) is saved as name (2).ext, name (3).ext… instead, and the summary says how many were renamed. Large batches show a progress overlay while they copy.
  • Contact sheet — right-click → Export → Contact Sheet (HTML)… → 512 px / 1024 px saves the whole tab as one self-contained HTML page: a numbered grid of every image, each captioned with its file name. The thumbnails travel inside the file itself, so it opens in any browser anywhere — wearing your current PadShifter theme (light or dark); each thumbnail renders at a fixed 512 px or 1024 px — your pick, remembered for next time — so quality never depends on how many images the tab holds; a very full tab simply makes a larger file.
  • Peek preview — right-click → View → Peek preview opens one image full-window at full quality — no zooming the canvas needed. With images selected it steps through only the selected images; with nothing selected it walks the whole board, starting top-left. ← / → or the mouse wheel step through them in reading order, and Esc or a click on the background closes it. The canvas itself never changes — peek is a look, not an edit.
  • Compare (A/B) — right-click → View → Compare (A/B) stacks two images in the peek viewer behind a draggable divider: everything left of the line is image A, everything right is image B — wipe across to spot the difference between renders. It pairs up your selection (or the first two on the board when nothing is selected), and with more than two images ← / → slide the pair along. Same full-quality decode as peek; Esc closes.
Canvas Tools: The Canvas supports four tools — Move Image, Pan Canvas, Add Text, and Draw — switchable from the toolbar or via keyboard shortcuts.

Text Editor Mode Editor

The built-in text editor provides a rich editing experience:

  • A lightweight text editing experience with line numbers and current-line highlighting.
  • Optional code folding — collapse indented blocks with the +/− markers in the editor's left gutter.
  • Bracket auto-closing and bracket matching highlights.
  • Auto-detection of text direction (RTL for Arabic/Hebrew, LTR for Latin/Greek/Cyrillic).
  • Find and Replace with case-sensitive search, forward/backward navigation, and match counting.
  • Click-through paths and links — hover a URL or file path in your text and hold Ctrl: the cursor turns into a hand and a click opens it — URLs in your browser (www. addresses included) and paths in Explorer with the file selected.
  • Clickable task checkboxes — click a [ ] or [x] box to flip it in place (one undo reverses it); fenced blocks stay literal text, so a box-looking line inside one never toggles.
  • Full keyboard shortcut support (copy, paste, select all, save, etc.).
  • Scroll position are persisted per tab, so you return exactly where you left off.

Grouping & Locking

ShortcutAction
Ctrl + GGroup Selection
Ctrl + Shift + GUngroup Selection
Ctrl + LToggle Lock Selection
Working inside a group: hold Shift and click an item to select it on its own, or hold Shift while dragging a marquee — only the items you touch are selected instead of the whole group. With two or more of them selected, Ctrl + G turns them into a new, separate group while the rest of the original group stays grouped; Ctrl + Shift + G releases the selection back as singles. Locked groups are atomic — you cannot select inside one, so unlock it first with Ctrl + L.
